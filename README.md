# Chronoscope

An interactive exploration of time's dimensionality — why our universe has exactly one time dimension, and what happens to physics when it doesn't.

## Run
Double-click `index.html`. Works offline (fonts fall back).
School edition (mainstream + frontier only): `index.html?edition=school`. See `HANDOVER.md`.

## Structure
- `index.html` — entry point
- `src/` — per-panel JavaScript
- `archive/` — completed specs and superseded material
- Project docs: `CLAUDE.md`, `ACTIVE.md`, `spec.md`, `DESIGN.md`, `decisions.md`, `todo.md`, `sources.md`
